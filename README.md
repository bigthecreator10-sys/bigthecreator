# BIG THE CReator

Repository-ready version of the BIG THE CReator website.

## Vercel environment variables
Set these in Vercel before using the backend:
- DATABASE_URL = Neon PostgreSQL connection string
- ADMIN_TOKEN = a long random secret for /admin.html

Do not commit .env files, passwords, API keys, or tokens.

## Included
- Responsive landing page
- User's supplied hero photograph
- Nigerian bank transfer payment details
- Booking, enquiry and payment-submission APIs
- Neon PostgreSQL persistence
- Private token-protected admin dashboard
